# autotrader-io

**빌드만 하는 저장소입니다.** 소스도, 만든 앱 파일도 여기에는 없습니다.

| | |
|---|---|
| 여기(공개) | 빌드 순서 한 장 (`.github/workflows/autotrader-build.yml`) |
| 비공개 `autotrader` | 소스·서명키·비밀번호·만든 앱 파일 전부 |

## 왜 나눴나

비공개 저장소는 GitHub Actions 사용 시간에 한도가 있고 다 썼습니다
(2026-11-18, 빌드가 단계 하나 못 돌고 2초 만에 죽었습니다).
**공개 저장소의 Actions 는 무료·무제한**이라 돌리는 일만 이쪽으로 옮겼습니다.

## 여기 없는 것

- 소스 — 돌 때 비공개 저장소에서 받아오고, 끝나면 사라집니다
- 서명키·비밀번호 — 비공개 저장소의 `secrets/` 폴더에만 있습니다
- 만든 APK·AAB — 비공개 저장소의 릴리스로 올라갑니다

여기 있는 비밀값은 **비공개 저장소를 읽을 토큰 하나**뿐이고, 그 값은
GitHub 밖으로 나오지 않습니다(넣은 사람도 다시 볼 수 없습니다).

## 이 파일을 복사해 가도

Secrets 는 따라가지 않습니다. 첫 단계(소스 받아오기)에서 바로 막힙니다.
